Usage Guide

How to use VarSwitch

Follow these steps to switch API environments safely.

1
Claude Code configs
Add or import Token/Base URL configs, then switch to sync system env, editors, and Claude settings.
2
Codex CLI configs
Manage Codex API Key, Base URL, model, provider, auth mode, diagnostics, and runtime backups.
3
Codex Toolbox
Install plugin marketplaces, repair bundled plugins, sync Codex sessions, and bind mobile control.
4
Skills, prompts, and MCP
Use toolbar entries to edit Claude Skills, CLAUDE.md prompt templates, and MCP server JSON.
5
Settings and backups
Set language, theme, tray behavior, editor paths, export/import profiles, and roll back backups.
6
Updates and restart tips
Check updates from the home page. After switching configs, restart terminals and editors to apply env vars.
