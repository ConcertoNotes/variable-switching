# 独立供应商配置弹窗交互反馈优化设计

## 范围

本次仅改 Claude、Codex、Grok、Gemini 四个独立配置弹窗，不改“添加统一供应商”页面及后端协议。保留现有保存、导入、模型获取、切换和 DeepSeek 特殊 Responses 规则。

## 目标

1. API Key 输入框提供显示/隐藏和粘贴操作。
2. 测试连接时提供按钮加载态及旁 inline 成功/失败状态胶囊。
3. 选择非自定义供应商预设时，联动覆盖相关连接字段、模型和协议，并以短暂黄色高亮提示覆写。
4. 配置名称为空或与同一应用其他配置重名时实时提示并禁用保存；编辑当前配置自身名称允许保留。

## 交互设计

### API Key

四个弹窗的 API Key 字段使用相对定位容器，输入默认保持 `type="password"`。右侧提供可访问的显示/隐藏按钮和粘贴按钮。粘贴调用浏览器剪贴板 API，成功后写入输入框并派发 `input` 事件；剪贴板不可用或读取失败时显示错误 Toast，密钥不写入日志。

### 测试连接

复用现有 `setButtonBusy`。测试开始时禁用按钮并显示旋转图标，成功后在按钮旁显示 `✓ 延迟 Nms`，失败后显示 `✕ <HTTP 状态> <摘要>`。保留现有模型结果和详细 endpoint 结果区域。地址或密钥发生输入变化、关闭并重新打开弹窗时清除胶囊状态。

### 预设级联

复用各 provider 的现有 preset 数据和 `apply*Preset` 函数：

- Claude：覆盖名称、Base URL、默认模型和 `apiFormat`。
- Codex：覆盖名称、Base URL、默认模型、provider 标识和 `wireApi`；继续由 DeepSeek 规则锁定 Responses。
- Grok：覆盖名称、Base URL、默认模型和 `apiBackend`。
- Gemini：保留当前自定义字段行为；若存在预设字段则沿用相同高亮机制。

“自定义”选项只切换选择状态，不覆盖用户已填写值。每个实际被覆盖的字段添加短暂 CSS 高亮类。

### 名称校验

为四个名称输入框绑定 `input`/`blur` 校验。空值和同一 provider 列表中的重复名称显示在输入框下方的 `text-rose-500 text-xs` 错误提示；编辑场景排除当前编辑 ID。校验失败时禁用对应保存按钮，Codex 的“保存并启用”同步禁用。提交函数保留同样的同步校验作为防绕过保护。

## 代码结构

新增通用 helper 负责：API Key 操作绑定、名称校验、连接状态胶囊渲染、预设高亮。通过 provider 字段映射接入四个弹窗，避免复制四套规则。现有 provider 提交函数和后端调用接口保持不变，仅在入口增加校验与状态更新。

## 错误处理

- 剪贴板读取异常：Toast 错误，不改变当前值。
- 测试连接异常：状态胶囊显示失败摘要，详细区域沿用现有 `describeVerifyError`。
- 名称校验失败：不发起后端保存调用，按钮保持禁用直到输入合法。
- 预设字段不存在时跳过该字段，不阻塞其他字段更新。

## 测试与验收

先新增会失败的 Node 测试，覆盖 DOM 结构、状态标签、预设覆盖字段和名称校验绑定；实现后运行 `node --test public/app.test.js` 及 JavaScript 语法检查。再启动本地前端，用浏览器分别打开四个弹窗，实际验证显示/隐藏、粘贴、测试连接成功/失败、预设黄色高亮、空名/重名禁用和编辑保留自身名称。
