Why VarSwitch

把分散的配置操作收进一个清晰工作流。

真正耗时间的不是模型调用，而是反复复制 Key、改 URL、重启终端、检查配置有没有写对。

01

不用手改环境变量

保存多套 API 配置，需要切换时直接点选，自动写入系统环境变量。

02

不再重复编辑配置文件

同步 VSCode settings.json 与 Claude 配置，减少漏改、错改和配置漂移。

03

交付客户更简单

下载安装、导入配置、点击切换，客户不需要理解 GitHub Releases 或手动路径。

FAQ

安装前只需要知道这些。

这个工具主要解决什么问题？

它帮你管理 Claude Code / API 的 Key、Base URL 和本地配置同步，避免手动改环境变量。

下载后浏览器提示风险怎么办？

如果出现拦截或无法验证开发者，请联系服务人员确认最新安装包和校验信息。

切换配置后需要重启终端吗？

系统环境变量通常需要新打开的终端才能读取最新值。已经打开的终端建议重启。
